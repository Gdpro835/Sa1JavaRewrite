# Sa1JavaRewrite

Java/Android-порт Sonic Advance в формате **Sketchware**. Исходники движка и игры находятся в `data/602/files/java`, игровые ресурсы — в `data/602/files/assets`.

## Новое ядро: deltaTime + OpenGL ES 2.0

В этой ветке старый цикл с ожиданием 63 мс заменён на `GLSurfaceView`:

- один update с фактическим `deltaTime` на кадр; **без fixed-step симуляции и догоняющих тиков**;
- GPU-отрисовка спрайтов, примитивов и эффектов через GLES 2.0, батчинг и кэш текстур;
- дробные накопители движения и таймеров, события пересечения порогов, анимации по прошедшему времени;
- обработка паузы, восстановления поверхности, мультитача и пересоздания Activity;
- сохранены структура Sketchware, Java 1.7 и существующие ассеты. Gradle-проект не добавлялся.

**Ограничителя на 15 FPS нет:** `FRAME_SKIP` удалён, `GLSurfaceView` работает в непрерывном режиме. Фактическая частота зависит от VSync/частоты экрана и производительности устройства. `0.063` в `GameTime` — единица авторских длительностей и скоростей, а не задержка между кадрами; менять её для повышения FPS не нужно.

**Статус:** ядро реализовано; выполнена широкая миграция игрового кода. Полная миграция всей игровой логики ещё не считается завершённой: остаются семантический аудит сценариев и проверка на Android. Успешная компиляция и headless-тесты не доказывают правильность всех персонажей, боссов, уровней и GPU-драйверов.

## Сборка в Sketchware

1. Сохраните резервную копию своего проекта. Используйте совместимую версию Sketchware Pro с поддержкой Java-файлов и manifest injection.
2. Восстановите существующий проект **602**, сохранив соответствие `mysc/list/602/project`, `data/602`, `resources` и `libs`. Это дерево проекта, не готовый APK и не Gradle-проект. Не перезаписывайте другой проект с таким же ID без резервной копии.
3. Подключите Java-файлы из `data/602/files/java` вместе с существующими ассетами/ресурсами и manifest-вставками. Особенно важно включить новые пакеты `GameEngine.time` и `com.sega.mobile.framework.opengl`.
4. Настройки: **Java 1.7**, **minSdk 14** (уже изменён в `project_config`), GLES **2.0**. `targetSdk 25` сохранён; обновление targetSdk/публикация в магазине — отдельная задача. Для компиляции существующего Android-кода используйте актуальный `android.jar`; проверка ниже выполнена с API 35.
5. Соберите и запустите APK на Android. Для текущих спрайтов нужен `GL_MAX_TEXTURE_SIZE >= 2048`; наличие GLES 2.0 проверяется при запуске.

Объявление `<uses-feature android:glEsVersion="0x00020000" android:required="true"/>` следует добавлять **непосредственно в корень генерируемого AndroidManifest.xml**, если версия сборщика предоставляет такой редактор. Не помещайте его в `app_components.txt`: эта вставка находится внутри `<application>`. Подробности и ограничения — в [описании миграции](docs/ENGINE_MIGRATION.md).

## Проверки без Sketchware

Нужны Python 3 и JDK 17. Скрипты не скачивают зависимости, не меняют проект и удаляют временные `.class` после выполнения.

```bash
# Чистые Java-тесты; Android SDK не нужен
./tools/test_engine.sh

# Компиляция всех Java-исходников; это НЕ сборка APK
ANDROID_JAR="$ANDROID_HOME/platforms/android-35/android.jar" ./tools/check_java.sh
```

Вместо `javac` можно указать `ECJ_JAR` и путь `JAVA`:

```bash
JAVA=/path/to/java ECJ_JAR=/path/to/ecj.jar ./tools/test_engine.sh
JAVA=/path/to/java ECJ_JAR=/path/to/ecj.jar \
  ANDROID_JAR=/path/to/android.jar ./tools/check_java.sh
```

Дополнительные сценарные проверки меню используют настоящий `TitleState`, анимации и ресурсы проекта, но заменяют Android-хост, звук и вывод пикселей тестовыми адаптерами. Для них нужен отдельный JVM JAR `org.json:json` (например, версия `20240303`); в APK он **не добавляется**:

```bash
ANDROID_JAR=/path/to/android.jar JSON_JAR=/path/to/json-20240303.jar ./tools/test_ui.sh
```

Последняя проверка: **294 проверки ядра + 128 сценарных проверок меню**, проверки структуры движка и компиляция **357 Java-файлов → 449 классов**. Сценарии покрывают повторный выбор персонажа клавишами и касаниями, подтверждение и повторный вход, вступление/пропуск для локализаций 0/6/8, дробное движение и GPU-путь затемнения. Проверялись интервалы, соответствующие 10–144 FPS, и нерегулярный deltaTime. **Это не запуск на Android, не тест GLES-драйвера и не замер FPS.** Полное прохождение игры не проверялось.

Архитектура, правила переноса игрового кода и матрица ручной проверки: [docs/ENGINE_MIGRATION.md](docs/ENGINE_MIGRATION.md).
